# Curriculum Blueprint (2025 Edition)

## Purpose & Orientation
This blueprint turns the Academy vision into a sequenced, instrumented learning system that blends sprint-based instruction, production-grade labs, and assistant-guided practice. Every learner navigates a governed pathway that mirrors how top AI labs (OpenAI, Anthropic, Google DeepMind, Meta FAIR, Microsoft) publish, evaluate, and deploy frontier systems.

## Pedagogical Pillars
- Evidence-first learning: every concept ties to a deliverable audited by automated evaluation and mentor review.
- Dual-track depth: theory briefs use current primary sources while labs replicate production workflows (MLOps, agent orchestration, governance).
- Assistant-scaffolded cognition: learners co-create with Scout, Coach, Critic, Archivist, and Companion agents to model safe AI deployment habits.
- Research cadence: weekly updates ingest releases such as GPT-5 preparedness previews (OpenAI, 2025), Gemini 2.5 system and Project Astra reports (Google DeepMind/Google Research, 2025), Grok 4 safety notes (xAI), Claude 4 artifacts (Anthropic), and Responsible Scaling Policy guidance.
- Responsible operations: guardrails, human-in-the-loop checkpoints, and risk instrumentation accompany every automation pattern.

## Signature Module Pattern
1. **Briefing** (10 min): primary source summary with annotated insights (coach agent cites lab reports, GitHub repos).
2. **Simulation** (45 min): guided prompts or system design exercise with automated checks from Critic agent.
3. **Build** (90 min): learner builds artifact (repo, policy, workflow) using governed templates.
4. **Evidence Review** (30 min): telemetry upload, rubric auto-fill, mentor feedback loop.
5. **Signal Reflection** (15 min): Companion agent surfaces longitudinal progress and alignment with sponsor goals.

## Frontier Integration Studios
- **Evaluation Science Studio**: recreate OpenAI Evals, Anthropic red-teaming prompts, and Stanford HELM 2024 scenarios to compare agent responses.
- **Toolchain Reliability Lab**: deploy reference implementations from Microsoft Semantic Kernel, LangGraph, and AutoGen; add monitoring via Langfuse and OpenTelemetry.
- **Safety & Policy Immersion**: analyze Google DeepMind's safety evaluations, UK AI Safety Institute measurement templates, and Meta AI's Llama Guard policies; craft enterprise-ready control libraries.
- **Knowledge Systems Workshop**: build multi-modal retrieval pipelines using Qdrant/pgvector, integrate Google Research's data cards framework, and benchmark against OpenAI Knowledge Graph patterns.
- **Frontier Research Sprints**: synthesize weekly lab releases (e.g., OpenAI Alignment Research Center reports, Anthropic interpretability notebooks, DeepMind robotics updates) into co-authored insight briefs.

## Assistant Orchestration & Toolchain
- Scout ingests RSS feeds, arXiv abstracts, GitHub releases (LangChain, LlamaIndex, NeMo Guardrails) and produces diff-aware research briefs.
- Coach pairs learners with guardrailed coding sessions, referencing Microsoft Copilot Studio safety patterns for staged deployment.
- Critic executes automated eval suites (toxicity, jailbreak, factuality) leveraging OpenAI Evals, Anthropic Safety Spec, and Meta's Prompt Guard heuristics.
- Archivist maintains Evidence Locker metadata, issues verifiable credentials through Open Badges, and aligns with W3C VC standards.
- Companion personalizes nudges, well-being checks, and sponsor-aligned milestones informed by Google re:Work psychological safety research.

## Evidence, Assessment & Credentials
- Rubrics: Explorer, Builder, Architect, Strategist, Luminary - mapped to NIST AI RMF functions (Govern, Map, Measure, Manage).
- Automated pipelines: integrate GitHub Actions, Langfuse analytics, and evaluation dashboards; surface anomalies for mentor review.
- Credential ladder: micro-badges per galaxy, sprint certificates with telemetry snapshots, full Architect Credential after capstone defense and governance audit.
- Sponsor reporting: monthly digest with outcome metrics (time-to-signal, guardrail coverage, stakeholder alignment) and roadmap adjustments.

## Research Refresh & Intelligence Loop
- Weekly: Scout + mentors triage new releases (system cards, policy updates, GitHub stars) and update module references.
- Monthly: Curriculum council reviews emerging papers (e.g., Anthropic's interpretability series, OpenAI superalignment updates, DeepMind automated governance studies) and refresh labs.
- Quarterly: Host Frontier Forum with industry partners, open-source maintainers, and policy experts to recalibrate objectives.
- Continuous: Maintain changelog in `docs/curriculum/changelog.md` with assistant-generated diffs summarizing what changed and why.
