1. Log signals in frontier digest queue with impact tags (curriculum, tooling, governance, operations).
2. Evaluate curriculum impact: update modules, labs, and playbooks referencing `docs/curriculum/lab-teaching-alignment.md`.
3. Create Jira/Linear tickets (placeholder) for development items (e.g., evaluation harness enhancements, dashboard features).
4. Push updates to Evidence Locker and changelog (`docs/curriculum/changelog.md`) with citations.
5. Review adoption metrics (system card submissions, evaluation harness usage, digest engagement).
